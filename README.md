# CMPM 121 S01: Click Counter

This project is a simple interactive webpage made with TypeScript using the CMPM 121 S01 starter template.

I changed the button’s click handler so that each click increases the counter by one and updates the number displayed on the page.

To run the project locally, run `deno task setup`, then `deno task dev`. Run `deno task ci` to check formatting, linting, types, and the production build.
